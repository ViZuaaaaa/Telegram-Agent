## Что умеет

- 📌 **Сообщение всегда внизу ленты** — если после вашего сообщения набежало много чужих, агент удаляет старое и отправляет заново
- 🔁 **Два варианта текста** — чередует их сам, подряд не уходит одинаковый текст
- 📂 **Тексты в обычных файлах** — правите блокнотом, агент подхватывает без перезапуска
- 👥 **Несколько аккаунтов** — делят чаты между собой, работают по очереди
- 📥 **Импорт чатов списком** — из файла `категория | @username | подписчики`
- 🖥 **Фоновый режим** — работает без открытого окна, можно закрыть SSH/ПК
- 🛡 **Бережёт аккаунты** — умные интервалы, адаптивный темп при ограничениях Telegram
- 📊 **Статистика** — обновления и состояние по каждому чату

## Установка

### Windows

1. Скачайте **TGAgent-win.exe** (справа на этой странице, раздел Files, или в Releases).
2. Положите в отдельную папку (например `C:\TGAgent\`).
3. Запустите двойным кликом. Всё нужное программа создаст сама.

> Если Windows SmartScreen спросит — «Подробнее» → «Выполнить в любом случае»
> (программа не подписана сертификатом, это нормально для малого софта).

### Linux / VPS (Ubuntu)

1. Скачайте **TGAgent-linux** и загрузите на сервер:
   ```bash
   scp TGAgent-linux root@ваш-сервер:/opt/tgagent/
   ```
2. На сервере:
   ```bash
   cd /opt/tgagent
   chmod +x TGAgent-linux
   ./TGAgent-linux
   ```

## Первый запуск (5 минут)

**1. Лицензия.** Введите ключ, выданный при покупке.

**2. Вход в Telegram.** Нужны `api_id` и `api_hash` — бесплатно на
[my.telegram.org](https://my.telegram.org) → *API development tools*.
Затем номер телефона и код из Telegram.

**3. Чаты.** Меню → «Добавить чаты в работу» — выберите из списка
ваших чатов (Space — отметить, Enter — подтвердить) или импортируйте
файлом.

**4. Тексты.** Откройте папку `messages/` рядом с программой — там файл
для каждого чата. Внутри два варианта сообщения через строку `===`:

```
Первый вариант сообщения.
===
Второй вариант — агент их чередует.
```

**5. Запуск.** Меню → «ЗАПУСТИТЬ агента».

## Клавиши

| Клавиша | Действие |
|---|---|
| `↑` `↓` / `W` `S` | по меню |
| `Enter` | выбрать |
| `Space` | отметить чат |
| `Q` | остановить агента |
| `F` | уйти в фон (можно закрыть окно и SSH) |

Фоновая работа пишется в файл `agent.log` рядом с программой.
Вернуться к просмотру: «ЗАПУСТИТЬ агента» → «Открыть просмотр работы».
